# Analysis notebooks

Use notebooks to read saved scenarios and run artifacts, inspect timelines, and explain failures. Simulator transitions, policy implementations, metric definitions, and statistical procedures belong in `src/gym_sched` and its tests.

Before using a figure in the thesis, record its run directory, scenario/configuration hashes, source revision, and split. Export a standalone figure and its underlying table. Do not tune policies from the final test results or manually edit run artifacts to remove failed episodes.
