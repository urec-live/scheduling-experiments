Four small experiments

1. Build your starting scenario

Gym size means machine counts and member population. Floor dimensions and walking paths are not modeled; walking time is configured separately.

Generated members each have one exercise per available equipment type, with alternating plan order. The first N members are independent; the rest receive advice. Edit each profile afterward to change these assumptions.

Generating replaces the draft profiles and simulation settings. It does not run the simulation.

2. Configure behavior and sensing

Advice never reserves equipment. Refusal means returning to independent choice. Predicted and actual durations start equal; edit them in the profile editor to test uncertainty.

Complete scenario and simulation editors

Every existing model field is editable here, including exercise/equipment alternatives, prerequisites, duration predictions, outages, deadlines, and latent behavior. Apply scenario edits to refresh the profile list. Changing these fields edits the draft only.

Generate a scenario to begin.
